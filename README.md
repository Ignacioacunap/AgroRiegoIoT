# AgroRiegoIoT - Sistema de Riego Automático con IoT y Android

Aplicación móvil desarrollada en **Android Studio (Kotlin)** orientada al control y monitoreo remoto de sistemas agrícolas mediante comunicación Bluetooth (módulo HC-05/06) y microcontroladores Arduino.

## Características Principales:
- **Autenticación de Usuarios:** Control de acceso seguro al panel de control.
- **Control Manual:** Apertura y cierre remoto de electroválvulas de riego.
- **Modo Automático:** Activación de rutinas automatizadas mediante sensores.
- **Conectividad Bluetooth:** Enlace en tiempo real con hardware IoT.

## Tecnologías Utilizadas:
- Android Studio (API 37 compatible)
- Kotlin / XML
- Bluetooth SPP (Serial Port Profile)
